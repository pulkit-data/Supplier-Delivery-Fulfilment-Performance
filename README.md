# Supplier Delivery & Fulfilment Performance Analysis

This project analyzes supplier performance based on delivery time, defect rates, compliance, and order fulfilment to identify reliable and high-risk suppliers.

**Tools used:** SQL · Python · Tableau

## Project Overview
The dataset contains 777 purchase orders from 5 suppliers. The goal was to evaluate supplier reliability and provide clear recommendations for the procurement team.

## Key Insights
- **Alpha_Inc** is the best overall supplier (lowest defect rate at 1.81% and high compliance at 94%)
- **Epsilon_Group** has the highest compliance rate (98%) and low defects (2.60%)
- **Delta_Logistics** is the highest-risk supplier (defect rate 10.83%, compliance only 61%)
- **Beta_Supplies** also underperforms on quality and compliance
- Delivery speed is similar across suppliers (10–11 days), so quality and compliance are the real differentiators
- Overall defect rate is 5.64%, and compliance is 82.4%

## Recommendations
- Prefer Alpha_Inc and Epsilon_Group for critical and high-volume orders
- Place Delta_Logistics under performance review
- Work with Beta_Supplies to improve quality and compliance
- Set clear SLAs: Defect rate < 3%, Compliance > 90%
- Introduce regular supplier scorecards
